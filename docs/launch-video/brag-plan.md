# /brag plan — Online Examination & Quiz System

## Answers from inspection
- **What is it:** a Java desktop app where B.Tech CSE students take timed MCQ tests on 8 core subjects.
- **Who is it for:** students preparing for semester exams and placement tests, plus faculty/admins who manage the question bank.
- **What sets it apart:** Medium and Hard modes ask you to *predict the output of real code*, give a starting hint when you're stuck, and the analytics screen tells you which subtopics you're weak in.
- **Most impressive true claims:** 460 questions across 8 subjects and 46 subtopics; all 124 code-output answers were verified by actually running the code; 95 automated tests pass.
- **Visual hook:** a dark code block with "What does this Python code print?", then the hint appears and an answer is clicked.
- **Real UI shown:** quiz screen (code question, hint, answer), login with the password eye, dashboard, mode picker, result screen, analytics. Every screen is a real capture of the running app (Xvfb, 2x UI scale). The architecture diagram is the real `docs/diagrams/architecture.png`.
- **Tone:** `default`, punchy and clean, in the app's own palette.
- **Share caption:** "Can you predict the output? A Java Swing exam-prep app: 460 questions, code-output rounds with hints, and analytics that find your weak topics."

## Data note
The captures use the bundled demo account ("Demo Student") and test attempts generated by driving the real app. There is no real student data and no personal information.
